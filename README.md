# 저장소 활용 목적
본 저장소는 서울디지털대학교의 '바이브 코딩' 과정에서 진행하는 프로젝트 소스 코드를 올리고 관리하기 위한 곳입니다. 

# 프로젝트 소개
* 강의주차: 8주차 3교시 myRtnMaker 만들기
* 기능
  - 운동 루틴 타이머
  - 운동 과정 설명 (이미지+텍스트)
